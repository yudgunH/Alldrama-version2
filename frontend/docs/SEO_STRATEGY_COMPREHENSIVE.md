### 3. **Structured Data Phong Phú**

#### ✅ OrganizationStructuredData

```json
{
  "@type": "Organization",
  "name": "AllDrama",
  "alternateName": ["All Drama", "AllDrama.net"],
  "description": "Nền tảng xem phim trực tuyến hàng đầu Việt Nam",
  "potentialAction": {
    "@type": "SearchAction"
  }
}
```

#### ✅ HomepageSEOContent

- WebSite Schema với SearchAction
- BreadcrumbList cho navigation
- FAQPage cho câu hỏi thường gặp
- ItemList cho movie collections

**Lợi ích:**

- Rich snippets trong SERP

- Better understanding by search engines
